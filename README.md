# 🛠️ Vibration Diagnostics Tool (ระบบวินิจฉัยความสั่นสะเทือนเครื่องจักรกลหมุน)

สคริปต์ Python สำหรับวิเคราะห์สเปกตรัมความสั่นสะเทือน (FFT Spectrum) แบบอัตโนมัติ โดยรับค่าความถี่ (Hz) และแอมพลิจูดความเร็ว (mm/s) จากเซนเซอร์ 3 แกน (**H**orizontal, **V**ertical, **A**xial) เพื่อแปลงเป็นค่า **Order (X)** และวิเคราะห์หาสาเหตุความผิดปกติทางกลไกเบื้องต้นตามหลักวิศวกรรมซ่อมบำรุง (Predictive Maintenance)

---

## ✨ ความสามารถหลัก (Features)

* **คัดกรองสัญญาณรบกวนอัตโนมัติ (Noise Filtering):** ตัดยอดพีคที่มีแอมพลิจูดต่ำกว่าเกณฑ์ขั้นต่ำและสัดส่วนเปอร์เซ็นต์ที่กำหนด
* **แปลงหน่วยความถี่เป็น Order (X):** คำนวณเทียบกับความเร็วรอบจริงของเครื่องจักร (`RPM / 60`) พร้อมรองรับค่าความคลาดเคลื่อน (Tolerance)
* **ครอบคลุมการวินิจฉัย 8 รูปแบบอาการหลัก:**
  1. **Mass Unbalance** (Force, Couple, Overhung Rotor)
  2. **Angular Misalignment / Bent Shaft / Cocked Bearing** (ความผิดปกติในแนวแกน)
  3. **Parallel Misalignment** (การเยื้องศูนย์แบบขนาน)
  4. **Mechanical Looseness Type A** (ฐานเครื่องอ่อนแอ / Soft Foot)
  5. **Mechanical Looseness Type B** (โครงสร้างร้าว / โบลต์ขาตั้งแบริ่งหลวม)
  6. **Mechanical Looseness Type C** (ชิ้นส่วนภายในหลวม / ปลอกแบริ่งสึก)
  7. **Rotor Rub** (โรเตอร์เสียดสีกับชิ้นส่วนอยู่กับที่)
  8. **Sleeve Bearing Wear & Oil Whirl Instability** (แบริ่งกาบสึกหรอและฟิล์มน้ำมันไม่เสถียร)
* **ระบบอธิบายเหตุผล (Diagnostic Explanation):** หากไม่พบแพทเทิร์นที่ตรงกับกฎเกณฑ์ ระบบจะวิเคราะห์และชี้แจงสาเหตุประกอบ พร้อมแจ้งเตือนหากมียอดพีคปริศนา (Unexplained Peaks) เช่น ความถี่ลูกปืน, ฟันเฟือง หรือ Resonance

## 🚀 วิธีการใช้งาน (Usage)

1. เปิดไฟล์สคริปต์ Python ของคุณ
2. แก้ไขข้อมูลความถี่ (`Hz`), แอมพลิจูด (`mm/s`) และความเร็วรอบ (`rpm`) ใน **ส่วนที่ 1 (ข้อมูลนำเข้า)**:

```python
# ---------- 1. ข้อมูลนำเข้า (แก้ตรงนี้) ----------
f_h = [10.0, 4.2, 38.0, ...]  # ความถี่แกนแนวนอน (Hz)
f_v = [10.0, 26.0, 4.3, ...]  # ความถี่แกนแนวตั้ง (Hz)
f_a = [12.0, 21.0, 32.0, ...] # ความถี่แกนแนวแกน (Hz)

v_h = [78.0, 83.0, 2.0, ...]  # แอมพลิจูดแกนแนวนอน (mm/s)
v_v = [83.0, 2.0, 73.0, ...]  # แอมพลิจูดแกนแนวตั้ง (mm/s)
v_a = [3.0, 2.0, 1.0, ...]    # แอมพลิจูดแกนแนวแกน (mm/s)

rpm = 600  # ความเร็วรอบเครื่องจักร (RPM)
```

3. รันโปรแกรมผ่าน Terminal หรือ Command Prompt:

```bash
python vibration_diagnostics.py
```

## ⚙️ การปรับแต่งพารามิเตอร์ (Configuration)

คุณสามารถปรับความละเอียดและความเข้มงวดในการวินิจฉัยได้ใน **ส่วนที่ 2 (ค่าตั้ง)** ของโค้ด:

* `TOL = 0.08` / `REL_TOL = 0.01`: ช่วงความคลาดเคลื่อนของ Order ที่ยอมรับได้
* `MIN_PERCENT = 0.10` / `MIN_ABS = 1.0`: เกณฑ์ตัด Noise (ต้องสูง $\ge 10\%$ ของยอดสูงสุด และ $\ge 1.0\text{ mm/s}$)
* `REF_GLOBAL = True`: เทียบเกณฑ์ $10\%$ กับยอดสูงสุดรวมทุกแกน (ตั้งเป็น `False` เพื่อแยกคิดอิสระทีละแกน)
* `REQUIRE_BOTH_AXES = True`: บังคับให้อาการแนวรัศมีต้องปรากฏทั้งแกน H และ V จึงจะยืนยันผล
* `OIL_WHIRL_ONE_AXIS = True`: อนุญาตให้แจ้งเตือน Oil Whirl ($0.42\text{X}-0.48\text{X}$) แม้พบเพียงแกนเดียว
